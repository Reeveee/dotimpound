SA DOT v4.35.2 - Guided Checklist

Branched DIRECTLY from the approved SA DOT v4.35.1 Interactive Vehicle Inspection.

Goal:
Make filling out the vehicle inspection feel light, clear and enjoyable instead of presenting ten checks as one intimidating block.

Changes:
- New GUIDED mode is the default.
- Shows one inspection item at a time with a large icon, plain-English prompt and optional diagnostic.
- PASS & NEXT and ISSUE & NEXT automatically move forward.
- 10-step route across the top shows progress, tests, passes and issues at a glance.
- Friendly momentum messages change as the operator progresses.
- Previous / Next navigation and clickable step route.
- OVERVIEW mode keeps the existing v4.35.1 full checklist intact for users who prefer it.
- Existing TEST animations remain.
- Existing Tested / Pass / Issue counters remain.
- Existing saved checklist history and Supabase schema are unchanged.
- No 2D truck, no 3D viewer, no vehicle image system.
- No Supabase changes required.
