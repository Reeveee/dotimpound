SA DOT v4.35.25

DOT Truck Incident Report added to Discord Reports.

Workflow:
1. Date + Time (prefilled)
2. Reporting Employee + Name + Unit Number (prefilled from account)
3. Postal + Street
4. Incident Type Y/N: Disabled Vehicle, Traffic Control, Road Hazard, Accident Assistance, Road Closure, Debris Removal
5. Vehicle + Plate, Requested By dropdown (LSCSO/LSPD/SAST/SAFR/BCSO), road/lane shut down, Left/Right/ALL Y/N, Actions Taken

Each Continue step plays the tablet loading animation. Includes feed preview, Copy All, generated Discord PNG and Past Reports saving.
