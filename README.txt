SAN ANDREAS DOT IMPOUND PORTAL - INTERACTIVE RP VERSION

1. Extract the ZIP fully before opening it.
2. Open admin.html first.
3. Click + NEW IMPOUND and create a test vehicle (for example plate SCAT).
4. Open index.html, search SCAT and complete the player release/payment flow.
5. Return to admin.html. The vehicle will now show PAID.
6. Click RELEASE to mark the vehicle RELEASED.

IMPORTANT: This local version uses your browser's localStorage. It works as an interactive demo on one browser/device. For different players to use one public URL and have their payments appear live on your DOT computer, the next version needs a hosted shared database/backend.

All payments are fictional GTA roleplay only. No real financial information is collected.
