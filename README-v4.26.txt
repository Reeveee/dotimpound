SA DOT v4.26 — Expanded Vehicle Visual Library

- Expanded matching library covering 200+ popular US/European/Japanese/Korean model names and GTA-style aliases.
- 5 consistent impound-yard visual families: sedan, European/performance, muscle/coupe, pickup, wagon/SUV.
- 13 colour variants per visual family: black, white, silver, grey, blue, red, green, yellow, orange, purple, brown, pink, beige.
- Colour is now resolved independently from make/model, so entries such as Blue BMW M3, Red Audi RS6, Green Ford F-150 and White Dodge Charger no longer fall back to a fixed brand colour.
- Same image resolver is used by DOT Operator and LEO pages.
- Unknown models fall back to the closest generic sedan visual rather than a fixed black vehicle.

This is a visual reference system, not a claim that every image is an exact photograph of the typed real-world model. It selects the closest consistent impound-yard vehicle family and requested colour.
