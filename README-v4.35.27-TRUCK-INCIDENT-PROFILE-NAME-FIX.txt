SA DOT v4.35.27

- Truck Incident Report Unit Number still comes from the signed-in DOT account.
- Truck Incident Report Name now comes ONLY from Account -> Operator Profile.
- It no longer falls back to the login username, so local admin will not show 'admin / admin'.
- If no profile name is saved, the report shows a clear Account -> Operator Profile prompt.
- Saving the profile while the Truck Incident Report is open refreshes the report name.
