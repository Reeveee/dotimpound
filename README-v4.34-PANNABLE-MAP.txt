SA DOT v4.34 - Full High-Resolution Pannable Postal Map Prototype

Uses the newly supplied full high-resolution San Andreas map.
Controls:
- Click-drag to pan
- Mouse wheel to zoom
- + / - buttons to zoom
- Home button to reset
- Postal lookup focuses the map on the postal marker

Visual prototype only. No Supabase schema changes yet.
Known demonstration postals: 1042, 3036, 8040, 9146, 9332.
